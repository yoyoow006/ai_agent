# 测试登录随机验证规范

## Purpose

定义本地测试登录项目的认证、随机验证码和自动化回归边界，确保示例可离线运行且不被误认为生产级认证系统。

## Requirements

### Requirement: 测试项目必须安全保存和校验密码

系统 SHALL 提供用户注册与密码登录能力；密码 SHALL 使用每个用户独立的密码学安全随机盐和 PBKDF2-HMAC-SHA256 派生存储，密码比较 SHALL 使用恒定时间比较。

#### Scenario: 注册并开始登录

- **WHEN** 用户使用有效用户名和足够强度的密码注册
- **THEN** 系统保存随机盐与密码派生值，而不是明文密码
- **AND** 后续提交正确密码可通过密码校验阶段

#### Scenario: 密码或用户不存在

- **WHEN** 登录提交未知用户、非字符串用户名或错误密码
- **THEN** 系统不区分对外错误原因
- **AND** 不创建验证码挑战，也不返回会话 token

### Requirement: 登录必须使用随机一次性验证码

系统 SHALL 在密码校验通过后创建 6 位数字随机验证码挑战；验证码 SHALL 来自密码学安全随机源，具有有效期、最大尝试次数和一次性使用语义。

#### Scenario: 生成验证码

- **WHEN** 用户通过密码校验并创建验证挑战
- **THEN** 验证码是 000000 到 999999 之间的 6 位数字
- **AND** 相邻两次生成的验证码不因普通随机种子而可预测

#### Scenario: 验证码过期或超限

- **WHEN** 验证码过期或同一挑战错误次数达到上限
- **THEN** 挑战失败且不能再用原验证码换取会话 token

### Requirement: 完整登录必须同时通过密码和验证码

系统 SHALL 只在用户存在、密码正确、验证码未过期且未超过尝试上限时返回会话 token；任何失败路径 SHALL NOT 泄露明文密码或验证码。

#### Scenario: 输入正确验证码

- **WHEN** 已通过密码校验的用户在有效期内输入正确验证码
- **THEN** 系统返回密码学安全随机生成的会话 token
- **AND** 原验证码挑战被消费，不能重复使用

#### Scenario: 输入错误验证码

- **WHEN** 用户提交错误验证码且未超过尝试上限
- **THEN** 系统拒绝登录并递增尝试计数
- **AND** 不返回会话 token

### Requirement: 测试项目必须保持本地演示边界

测试项目 SHALL 仅使用 Python 标准库和内存状态，不联网、不持久化账户、不接入短信或邮件；验证码投递 SHALL 通过可注入通道抽象，默认命令行演示仅在本地输出。

#### Scenario: 运行本地演示

- **WHEN** 用户按 README 运行命令行演示
- **THEN** 项目在同一进程内演示注册、随机验证码投递和登录成功流程
- **AND** 不访问网络或外部服务

### Requirement: 认证行为必须有自动化回归

系统 SHALL 为密码哈希、安全盐来源、默认迭代强度、错误路径、验证码随机性、有效期、尝试上限、一次性使用和 token 生成提供单元测试。

#### Scenario: 运行测试项目测试

- **WHEN** 在项目目录运行 `python3 -B -m unittest discover -v -s tests -p 'test_*.py'`
- **THEN** 全部测试通过
- **AND** 测试不依赖真实短信、邮件或网络服务

# 设计与确认范围

用户已确认 proposal/spec/tasks 和三项默认假设。此文件补记同一设计，不增加实施范围。

- 缓存仅供 fast 使用，默认全量与 required 实际执行；声明式输入清单包含规则、技能、规范、实现和命令身份，失效时重新计算，缓存异常不影响真实执行结果。
- 保留 `--fast`、默认全量、`--require-openspec` 与 `--archive-light`，显式 `--standard` 等价默认全量。变更触及治理文件时给出确定性 required 升级要求；目标项目测试仍由 tasks 精确命令现跑。
- 模板生成只创建用户指定的空目标目录；填充后只读预检区分状态、场景、命令和本地整合策略。历史产物不强制迁移。
- 当前是仅 Codex 的安装目标（`.ai/assistant-profile.json`），不存在 Claude 与安装器资产树；同步现存入口与共享契约，缺失资产不凭空创建。

不引入新依赖。实现使用 Python 标准库与现有 Bash。严格验证必须取得真实退出结果；缺少 OpenSpec CLI 会阻断终验。比较替代方案后沿用现有入口，而非另造平行状态与校验器。

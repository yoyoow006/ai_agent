# 设计要点

## 关键决策

1. **使用真实路径而非用户别名**：安装器对路径中任一符号链接均失败关闭；本变更固定使用 `/media/shitou/石头/wksource/yuxiaor_prj_2025`。
2. **复用既有安装器**：不手工复制文件，确保清单、事务发布、回滚、受管 `.gitignore` 块和重复执行语义由已验证实现承担。
3. **保留冲突入口**：目标旧 `AGENTS.md` 先重命名为 `AGENTS.pre-codex-workflow.md`，满足安装器不覆盖差异内容的约束，也保留用户可回滚原文。
4. **只安装 Codex 单侧**：用户明确请求 Codex；目标现有 `CLAUDE.md` 不属于本变更，不由 Codex 安装器改写。
5. **不建立目标 Git 基线**：目标根目录不是 Git 工作树且包含多个嵌套业务仓库；本变更不执行 `git init`、提交或修改嵌套仓库。

## 风险与边界

- 目标根目录无 Git 保护，安装器事务负责发布阶段回滚；旧入口备份负责入口冲突回滚。
- 安装器写入根级工作流资产与 `.gitignore` 受管块，但不触及嵌套业务仓库。
- 旧 `AGENTS.md` 中引用的 hook 与 `.claude` 机制未随 Codex 安装包提供；本变更只保留原文，不承诺移植或激活这些旧机制。
- OpenSpec CLI 已在当前机器可用；若目标验证时不可用，严格验证不得记为通过。

## 待独立计划细化

- 安装前检查和备份的精确顺序。
- 安装失败时恢复旧 `AGENTS.md` 的回滚步骤。
- 目标验证命令、证据位置与归档后的源仓库收尾策略。

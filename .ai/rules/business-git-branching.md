# 业务代码任务分支规则

业务代码仓（包括嵌套业务仓，如 `yuxiaor-pms`、`yuxiaor-xxljob`、`yuxiaor-e-signature`）禁止在 `master`、`main` 或默认远端分支上直接修改或提交业务实现。

修改业务代码前必须：

1. 确认当前业务仓库分支和未提交状态。
2. 若仍在默认分支，先创建并切换到任务分支，建议命名：
   `feature/<变更名或业务主题>`。
3. 任务分支必须从明确的基线提交或默认分支创建；存在并行开发时优先从需求指定基线创建。
4. 只把任务相关业务代码提交到任务分支；不得把用户已有未提交文件带入提交。

发现业务仓库默认分支领先远端且包含本任务提交时，必须立即停止后续提交，先创建任务分支保留提交，并将默认分支恢复到远端默认分支；该恢复操作需用户确认。

例外：仅读取代码、生成 patch、或用户明确要求在默认分支处理的动作不受此规则限制，但不得提交业务实现。

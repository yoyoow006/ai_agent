# Build——实现

1. 读取 `changes/<名称>.md`，核对模式与状态；状态不是"待确认"或未获确认时停止。
2. 标准：创建/切换 `feature/<变更名>` 分支。严格：用 `git worktree` 隔离。
3. 把状态改为"进行中"。
4. 运行时行为/缺陷修复用 TDD；纯文档用内容+格式校验。
5. 每个职责单元跑通验证后提交一次。
6. 测试失败先用 systematic-debugging 找根因，不盲目改。
7. 全部任务勾完、验证全绿后，状态改"待验证"，交 verify。
